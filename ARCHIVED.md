# ADAD Project Status: Archived

> [!WARNING]
> **ADAD is no longer maintained as of 2026-08-02.**

This repository is preserved as a historical implementation and migration
reference. It will not receive new features, routine bug fixes, compatibility
updates, releases, or support.

## Successor

Active design work has moved to:

**ADHD — Architecture-Driven Harnessed Development**

ADHD is a clean successor rather than an in-place ADAD upgrade. Its direction
uses a dual SSOT (System Map plus semantic specifications), architecture-scoped
autonomous development, risk-based gates, and high-standard layered
verification. It intentionally does not carry forward Frozen Tasks, JIT Source
Ownership, Source Locks, Checkpoints, stable freshness chains, or the heavy
evidence/recovery control plane.

The ADHD repository has not yet been published at a public URL. This notice
will not guess or reserve one.

## Repository policy

- Existing source, releases, documentation, and history remain available as-is.
- Historical documentation describes ADAD at the time it was developed; it is
  not a current recommendation or maintained contract.
- New issues and pull requests should not be opened with an expectation of
  implementation or support.
- Existing packages may continue to work in their previously supported
  environments, but no future compatibility is promised.
- No migration from ADAD to ADHD should be inferred until ADHD publishes an
  explicit migration specification.

## Security

This archival status is not a security-support commitment. Do not deploy ADAD
in a new security-sensitive environment on the assumption that vulnerabilities
will be patched.

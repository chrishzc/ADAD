# ADAD Documentation Archive

> [!WARNING]
> ADAD is no longer maintained as of 2026-08-02. See
> [ARCHIVED.md](../ARCHIVED.md).

Every document under `docs/` is retained for historical, audit, or migration
reference. Status labels such as planned, completed, accepted, released, or
future work describe the legacy ADAD project at the time the document was
written. They do not create an active maintenance roadmap.

In particular:

- `SPEC_INDEX.md` and `specifications/` are frozen legacy contracts.
- `RELEASE_SOP.md` is historical and must not be used to infer a future ADAD
  release.
- `ADAD_reviewer_loop_design.md`, task plans, ADRs, and roadmap documents are
  implementation history, not active ADHD specifications.
- ADHD specifications live in the separate ADHD repository and must not be
  reconstructed by selectively combining these legacy documents.

The successor project is **ADHD — Architecture-Driven Harnessed Development**.
Its public repository URL has not yet been published.
